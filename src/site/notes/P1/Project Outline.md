# Project Brief

**Text editor with voice text input for any Indian language**  

We Indians type so little in our mother tongues. (Don’t get me started on this). A lot of our work has focussed on text input. Now, a lot of voice-based text input is possible (even in Indian languages). But voice based text input is error prone. And we don’t have a text editor that is solely or mainly voice-based. This project needs to be an exploratory project about designing a voice-based text editor. Conceptually, it is similar to Aniket’s P2 that proposed Swarachakra (don’t have a softcopy of it, so please ask Aniket to share it with you [aniketsarangdhar@gmail.com](mailto:aniketsarangdhar@gmail.com)). This project could be done either by BDes or by MDes students. Only one student can work on these projects at a time.**
